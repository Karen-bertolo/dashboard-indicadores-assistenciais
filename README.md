# Dashboard de Indicadores Assistenciais

Projeto desenvolvido em Power BI para monitoramento de indicadores assistenciais e apoio à tomada de decisão.

## Objetivos
- Acompanhar indicadores de atendimento
- Monitorar tempo de permanência
- Facilitar a análise de desempenho

## Ferramentas utilizadas
- Power BI
- Power Query
- Excel

## Funcionalidades
- KPIs
- Gráficos interativos
- Segmentação de dados
- Análise de indicadores
